# Roadmap

What is planned, roughly in order. Suggestions welcome in issues.

## Next

- Faster renders on older machines: pre-composite static layers, hardware
  final encode by default where it matches quality.
- More looks, and a way to save your own look from a reference video.
- Premiere / Resolve / Final Cut XML export with the graphics as separate
  layers (today: a rough EDL).
- Windows one-step tool install.

## Later

- Privacy sweep for screen recordings: OCR the footage, blur emails and
  account names, then OCR the output until clean (see the production playbook).
- Companion document generator for teaching videos.
- Multi-camera sync for two-angle interviews.
- Music suggestions from a user's own library, matched to pacing.

## Not planned

- Hosted rendering or uploads of user footage.
- Generated B-roll of real people.
